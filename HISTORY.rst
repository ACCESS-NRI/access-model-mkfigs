History
=======

v0.1.0 (2026-11-10)
-------------------

Initial release on PyPI and GitHub.

* Support evaluation figure workflows for ACCESS-OM3 and ACCESS-CM3 paper repositories.
* Run analysis notebooks and publish figures and rendered notebooks to Figshare.
* Improve Figshare upload reliability, recovery, and integrity checks.
* Support re-running notebooks and replacing previously generated outputs.
* Add local and ReadTheDocs preview workflows without Figshare uploads.
* Support optional categories on experiment landing pages.
* Record the actual mkfigs Git version for reproducibility.
* Improve test coverage, error reporting, and CI compatibility.
